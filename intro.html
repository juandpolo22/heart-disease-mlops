Predicción de falla cardíaca con MLOps local#

Proyecto Integrador de Aprendizaje Automático (sección 10.20)

Autores: Juan Polo y Gabriela Pallares

Repositorio del proyecto

Todo el código (API, Docker, Kubernetes, CI, notebooks y reporte de Evidently) está en GitHub:

github.com/juandpolo22/heart-disease-mlops

También se puede abrir desde el botón de repositorio de la barra superior de este libro.

Contexto del problema#

Las enfermedades cardiovasculares son la principal causa de muerte en el mundo [World Health Organization, 2021], y detectarlas a tiempo es fundamental para evitar complicaciones graves. Con la disponibilidad de datos clínicos estructurados es posible usar aprendizaje automático para estimar el riesgo de falla cardíaca.

El proyecto construye, con scikit-learn [Pedregosa et al., 2011], un modelo de clasificación binaria que predice si un paciente está en riesgo de falla cardíaca (HeartDisease = 1) o no (HeartDisease = 0), y lo lleva a producción local con un flujo de MLOps [Sculley et al., 2015]: FastAPI, Docker, Kubernetes (Minikube), GitHub Actions y Evidently. Todo se ejecuta en un equipo local, sin servicios en la nube.

Datos#

El dataset es Heart Failure Prediction [fedesoriano, 2021] (Kaggle). El archivo heart.csv está incluido en la carpeta notebooks/ del repositorio.

Resultados#

Se comparan cuatro clasificadores (LogisticRegression, RandomForestClassifier, KNeighborsClassifier y GradientBoostingClassifier), cada uno dentro de un Pipeline optimizado con GridSearchCV y StratifiedKFold de 5 pliegues. El modelo se elige por el AUC de validación cruzada, usando solo el conjunto de entrenamiento.
